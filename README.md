# Hey, I'm Komal 👋

Third-year CSE undergrad at NMIT, Bangalore. I build Android apps and web tools that try to solve actual problems — and I'm working my way toward specializing in AI/ML engineering.


---

### 🚀 What I'm building

**🛟 Women Safety Companion App**
`Android Studio` · `Java` · `XML` · `Google Maps API`
A real-time Android safety app with one-tap and shake-triggered SOS alerts. Notifies emergency contacts with live GPS in under 10 seconds, plus continuous background location sharing so trusted contacts can track you during an emergency.

**🔍 CrimeLens — Image Processing in Crime Investigation**
`Python` · `Flask` · `OpenCV` · `HTML/CSS` · `JavaScript`
A Flask web app for analyzing crime-related images — upload, preview, and enhance images, with OpenCV-powered face and object detection to flag persons and suspicious objects.
